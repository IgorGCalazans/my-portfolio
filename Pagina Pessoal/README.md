# 💻 Portafolio Web Personal - Página de Presentación

Este proyecto es mi sitio web personal y portafolio interactivo, diseñado como una carta de presentación para el mercado de desarrollo de software en España. Funciona como un ecosistema centralizado donde los reclutadores y líderes técnicos pueden conocer mi perfil, acceder a mis redes profesionales y probar mis aplicaciones directamente.

## 🚀 Tecnologías Utilizadas

- **HTML5:** Estructuración de contenidos semánticos y accesibles.
- **CSS3 Moderno:** Diseño de tarjetas flotantes con Flexbox, control de alineación inteligente, sombras suaves (`box-shadow`), efectos dinámicos de movimiento (`transform: translateY`) y transiciones de cámara lenta (`transition`).
- **JavaScript Integrado:** Conexión y llamada a funciones de lógica condicional para la ejecución de proyectos integrados.

## 💡 Diferenciales de Ingeniería y Buenas Prácticas

- **Enlaces Seguros y de Alta Retención:** Todos los enlaces externos (LinkedIn y GitHub) están optimizados con el atributo `target="_blank"` para abrirse en pestañas separadas de forma segura utilizando `rel="noopener noreferrer"`, garantizando que el usuario nunca abandone el portafolio original.
- **Arquitectura de Layout Limpia:** Uso de propiedades avanzadas de CSS para crear un diseño tipo "dashboard" o menú de proyectos visualmente atractivo, eliminando la rigidez de los estilos por defecto del navegador.
- **Ecosistema Integrado:** El proyecto sirve como la base principal para lanzar y probar otros desafíos lógicos complejos de mi portafolio.
