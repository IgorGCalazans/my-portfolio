# 🚀 Meus Desafios de Lógica e Programação

Este repositório foi criado para unificar e organizar todos os desafios, projetos e exercícios práticos desenvolvidos durante os meus estudos de Lógica de Programação e Desenvolvimento Web.

## 📂 Projetos Inclusos

*   **💻 Pagina Pessoal:** Meu cartão de visitas no mercado, apresentando minhas redes sociais e introdução ao mundo dev.
*   **🍽️ Página de Receitas Culinárias:** Um site de culinária totalmente semântico, acessível e responsivo para dispositivos móveis utilizando CSS Flexbox avançado.
*   **💰 Calculadora de Consumo:** Sistema inteligente integrado para ajudar usuários (focado em acessibilidade/UX) a calcularem gastos de viagem.

## 🛠️ Tecnologias Praticadas
- HTML5 Semântico
- CSS3 Moderno (Flexbox & Responsividade)
- JavaScript (Lógica condicional, operadores lógicos e funções)
- Git & GitHub (Controle de versão profissional)
