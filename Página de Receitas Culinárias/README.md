# 🍽️ Página de Receitas Culinárias 

Este projeto foi desenvolvido como um desafio prático de desenvolvimento web e lógica de estruturação, focado em criar uma interface moderna, limpa e totalmente acessível.

## 🚀 Tecnologias Utilizadas 
-HTML semâtico (`<section>`, `<article>`, `<nav>`)
-CSS3 Moderno (Flexbox)
-Responsividade Avançada(`@media queries`)

## 💡 Diferenciais do Projeto
- **Acessibilidade:** Configuração de idioma nativo e espaçamento de linhas (`line-height`) otimizado para leitura na cozinha.
- **Responsividade:** O layout se adapta perfeitamente para celulares, empilhando o conteúdo de forma vertical sem quebrar a tela.
- **Navegação Inteligente:** Barra de navegação com rolagem suave (`scroll-behavior`).
